# v0.1.3 — Restore Basic Reliability

Status: implemented locally; not tagged, published, or pushed. Verification date: October 16, 2026. Proposed release deadline: October 23, 2026 (Asia/Karachi).

## Delivered changes

| Requirement | Implementation |
|---|---|
| REL-01: Startup | Valid Python source, base-only public imports/help without service calls, lazy optional SDKs, and actionable missing-SDK errors |
| REL-02: Version | `pyproject.toml` is authoritative; runtime version comes from installed distribution metadata; wheel/source metadata identify 0.1.3 |
| REL-03: Configuration | Strict shapes/types/ranges, contextual active-provider validation, safe YAML errors, no CLI fallback, and preserved deliberate Python defaults |
| REL-04: Empty evaluation | Zero evaluated questions fail across CLI/scorer/facade; empty authoring still works; failed reruns invalidate previous reports |
| REL-05: Files | Candidate validation, preflight before generation, atomic per-file writes, permission preservation, explicit replacement, and unchanged existing data on tested ordinary failures |
| REL-06: Documentation | Corrected setup/configuration/CLI examples, local HTTP fixture, recovery instructions, and known limitations |

`init` copies hardcoded examples; it does not create questions from documents or embeddings. Use verified manual cases, capture, or document-based generation followed by review. See the [quick start](../getting-started/quick-start.md).

## Compatibility changes

- Requires Python 3.11 or newer. Python 3.10 support was removed after the initial reliability verification.

- Invalid CLI settings no longer silently become defaults. Correct the reported field or selected path.
- No approved/matching questions means a failed evaluation, even when quality-failure exit behavior is disabled.
- Python users supplying an adapter may still omit the conventional default configuration file; custom missing files and broken links fail.
- Question-list replacement uses `generate --output PATH --overwrite`. Output and auto-capture modes cannot be combined.
- Invalid existing auto-capture goldens must be repaired or a new destination selected. They are never reset automatically.
- Use an editable installation for source development; runtime version resolution requires installed distribution metadata.
- No baseline database/schema migration is required.

## Reproducing the checks

From the project root:

```bash
uv sync --locked --dev --python 3.12
uv run pytest tests/ --run-integration -q
uv run ruff check src/
uv build
```

The local HTTP integration requires permission to bind a localhost socket. Base installation and artifact verification should run separately from a development environment:

```bash
uv venv /tmp/longprobe-wheel-check --python 3.12
uv pip install --python /tmp/longprobe-wheel-check/bin/python dist/longprobe-0.1.3-py3-none-any.whl
/tmp/longprobe-wheel-check/bin/python -I scripts/verify_v013_release.py
```

The verification script uses the installed wheel rather than the editable checkout, confirms optional SDKs/test dependencies are absent, starts the synthetic HTTP example, and prints artifact SHA-256 hashes. Keep the wheel environment base-only. Supported-version tests run on Python 3.11 and 3.12. The earlier Python 3.10 result is historical and does not indicate current support.

## Remaining limitations

- Normal evaluation does not wire `embedder` settings into vector-only backends. Pinecone/Qdrant text-question integration remains deferred.
- Semantic matching is word-frequency similarity, not neural embedding matching.
- The default pytest adapter fixture still needs an override.
- Baseline-save quality policies differ between CLI/Python; baseline compatibility and equal-recall evidence-change detection are unchanged.
- JSON stdout may still include notices/trailing command output; general cleanup is deferred.
- Explain does not calculate rank/score deltas. Watch still reacts only to golden-file changes.
- No automatically verified ground truth is promised for LLM-generated/captured evidence; review drafts before approval.
